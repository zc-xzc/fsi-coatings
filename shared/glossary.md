# 术语表 Glossary

> 跨方向积累，每读一篇新论文补充

## 涂层方向
- **CSSS** — Critical State for Safe Service 安全使用临界状态
- **RPT** — Rate Process Theory 速度过程理论
- **Pull-off Test** — 拉开法附着力测试
- **Thermal Mismatch** — 热失配
- **Critical Erosion Angle** — 临界冲蚀角

## 流固耦合方向
- **FSI** — Fluid-Structure Interaction 流固耦合
- **ALE** — Arbitrary Lagrangian-Eulerian 任意拉格朗日-欧拉法
- **IBM** — Immersed Boundary Method 浸入边界法
- **CFD-DEM** — CFD + Discrete Element Method 气固两相流耦合

## 数值方法
- **FEM** — Finite Element Method 有限元法
- **CZM** — Cohesive Zone Model 内聚力模型
- **Phase-field** — 相场法（用连续场描述断裂/相变）
- **XFEM** — eXtended FEM 扩展有限元
