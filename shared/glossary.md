## 涂层与腐蚀方向

| 术语 | 英文 | 简短解释 |
|------|------|---------|
| 安全使用临界状态 | CSSS (Critical State for Safe Service) | 涂层失效前的临界评估点 |
| 速度过程理论 | Rate Process Theory (RPT) | 高分子应力老化的微观热激活理论 |
| 活化能 | Activation Energy | 化学反应/分子运动需跨越的能量壁垒 |
| 银纹 | Crazing | 聚合物在应力下的微裂纹空隙网状结构 |
| 拉开法 | Pull-off Test | 垂直涂层方向施加拉力测附着力 (GB/T 5210) |
| 热失配 | Thermal Mismatch | 不同材料热膨胀系数不匹配导致的应力 |
| 临界冲蚀角 | Critical Erosion Angle | 冲蚀量最大时的入射角度 |
| 变形磨损 | Deformation Wear | 颗粒反复撞击导致的表面变形破坏 |
| 切削磨损 | Cutting Wear | 颗粒切削导致材料去除 |
| 重防腐涂装 | Heavy-duty Anti-corrosive Coating | 多层防护体系用于严酷环境 |
| 富锌涂层 | Zinc-rich Coating | 含锌粉的防腐涂层, 提供阴极保护 |
| 本征缺陷 | Intrinsic Defect | 涂层成膜过程中自然形成的微观缺陷 |

## 流固耦合与数值方法

| 术语 | 英文 | 简短解释 |
|------|------|---------|
| 流固耦合 | FSI (Fluid-Structure Interaction) | 流体与固体相互作用的力学问题 |
| 任意拉格朗日-欧拉法 | ALE (Arbitrary Lagrangian-Eulerian) | 动网格处理流固界面的方法 |
| 浸入边界法 | IBM (Immersed Boundary Method) | 固定网格上加力表示固体的 FSI 方法 |
| 离散单元法 | DEM (Discrete Element Method) | 模拟颗粒材料运动的数值方法 |
| CFD-DEM | Computational Fluid Dynamics - DEM | 流体-颗粒两相流耦合方法 |
| 相场法 | Phase-field Method | 用连续场变量描述断裂/相变 |
| 内聚力模型 | CZM (Cohesive Zone Model) | 界面开裂的牵引-分离本构 |
| 多物理场耦合 | Multi-physics Coupling | 多个物理场相互作用 (热-力-化) |
| preCICE | Precise Code Interaction Coupling | 开源多物理场分区耦合库 |
| 分区耦合 | Partitioned Coupling | 分别求解各物理域, 界面交换数据 |
| 整体耦合 | Monolithic Coupling | 同时求解联立方程组 |
| 有限元法 | FEM (Finite Element Method) | 求解偏微分方程的数值方法 |
| 计算流体力学 | CFD (Computational Fluid Dynamics) | 数值求解流体流动问题 |
| 扩展有限元 | XFEM (eXtended FEM) | 不依赖网格的断裂模拟方法 |

## 力学基础

| 术语 | 英文 | 简短解释 |
|------|------|---------|
| 本构方程 | Constitutive Equation | 材料应力-应变关系的数学描述 |
| 张量 | Tensor | 多分量物理量 (标量/矢量/二阶张量) |
| 弹塑性 | Elastic-Plastic | 加载先弹性后塑性的力学行为 |
| 粘弹性 | Viscoelastic | 同时具有粘性和弹性特征 |
| 热弹性 | Thermoelastic | 考虑温度效应的弹性本构 |
| 断裂韧性 | Fracture Toughness | 材料抵抗裂纹扩展的能力 |
| 应力强度因子 | Stress Intensity Factor (SIF) | 表征裂纹尖端应力场强度 |
| 能量释放率 | Energy Release Rate | 裂纹扩展单位面积释放的能量 |
