# 科研工作流

## 完整闭环
```
读论文 → Zotero管理 → Markdown笔记(topic内部) 
  → Python复现 → 写proposal → 提交代码 → 写论文
```

## 每日
- 上午: 读15面 + 写笔记到 topics/xxx/papers/xxx/notes.md
- 下午: 学工具/跑代码到 topics/xxx/codes/
- 晚上: 看综述/整理/计划明天

## 每周日
```bash
git tag v2026-08-01-weekN   # 方便回滚
git push --tags
```

## 论文命名规则
topics/{topic}/papers/{作者拼音}-{年份}-{英文关键词}/
例: qi-yanfu-2026-steel-bridge-coating/
