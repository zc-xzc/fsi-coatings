# 第3章 深度分析: 修正速度过程理论

## 这是全篇最重要的理论创新

## RPT回顾
- Eyring(1936): 热激活过程
- Zhurkov(1965): 加应力项 tf = t0·exp((U0-γσ)/kBT)

## 论文修正
加入微观能量耗散:
U_eff = U_0 - γσ - ΔU_damage
其中ΔU_damage来自微裂纹、空隙增长、分子链断裂

## 时变老化模型
P(t) = P0·f(t,T,σ,D)
- P: 附着力或厚度
- D: 累计损伤
- 附着力反映部分能量损耗(需拟合)
- 厚度变化形式一致(需计算)

这个修正贯穿全文:
第2章(初始缺陷) → 第3章(时变演化) → 第4章(寿命预测) → 第5章(动应力) → 第6章(冲蚀)
