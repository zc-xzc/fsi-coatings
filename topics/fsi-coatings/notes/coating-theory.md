> 来源: 戚彦福(2026) 第1章综述 + 其他文献 | 持续更新

## 1. 重防腐涂装体系

### 三层结构功能
```
┌─────────────┐
│   面漆       │ ← 耐候性/装饰/UV防护 (丙烯酸聚氨酯/氟碳)
├─────────────┤
│   中间漆     │ ← 屏障/增加厚度 (环氧云铁)
├─────────────┤
│   底漆       │ ← 附着力/阴极保护 (富锌环氧)
├─────────────┤
│   钢基材     │
└─────────────┘
```

### 三种防护机制
| 机制 | 原理 | 关键材料 |
|------|------|---------|
| **屏蔽作用** | 隔绝腐蚀介质 | 片状填料(云母氧化铁), "迷宫效应" |
| **缓蚀/钝化** | 在金属表面形成保护膜 | 铬酸盐/磷酸盐颜料 |
| **阴极保护** | 锌牺牲阳极保护钢基材 | 富锌底漆 |

## 2. 热循环老化

### 物理过程
- 涂层与基材热膨胀不匹配 → 热失配应力
- 温度变化 → 分子链断裂 → 脆性增强
- 吸水→膨胀→干燥→收缩→内应力
- 冰晶膨胀(低于0℃时)

### 关键理论: 热力学等效 (论文第2章)
```
非均匀温度场 → 热力学等效系数 → 等效均匀能量
                                     ↓
                             修正热应力模型
                                     ↓
                             空间特征分析
```

## 3. 速度过程理论 (RPT)

### 发展历程
| 时间 | 作者 | 模型 | 说明 |
|------|------|------|------|
| 1936 | Eyring | k = (kBT/h)·exp(-ΔG‡/RT) | 热激活过程基础 |
| 1965 | Zhurkov | tf = t0·exp((U0-γσ)/kBT) | 加入应力项 |
| 2026 | 戚彦福 | U_eff = U0 - γσ - ΔU_damage | 加入微观损伤耗能 |

### 修正RPT的物理意义
```
原始: 涂层老化 = 热激活化学反应
+应力: 应力降低活化能 → 加速老化
+损伤: 微观缺陷发展耗散能量 → 进一步加速
核心: 建立了宏观性能与微观机制的定量联系
```

## 5. 风沙冲蚀理论

### Finnie切削模型 (低角度, 塑性)
```
W_cut = (M·v²/p) · f(α)
```

### Bitter变形磨损 (高角度, 脆性)
```
W_def = (M·(v·sinα - ve)²) / (2ε)
```

### 论文修正 (第6章)
```
W_total,modified = (W_cut + W_def) · f(σ, T, UV)
```
- 应力+环境 → 涂层变脆 → 切削减少/变形增加
- 交互作用提升预测精度19%
