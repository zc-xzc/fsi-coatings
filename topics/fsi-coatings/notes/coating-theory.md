# 涂层力学理论

## 重防腐涂层结构
面漆(耐候) → 中间漆(屏障) → 底漆(附着力+阴极保护) → 钢基材

## 热循环理论
热力学等效原理: 非均匀温度 → 等效能量 → 修正热应力 → 空间特征模型

## RPT修正 (核心创新)
原始RPT(Eyring 1936): k = (kBT/h)·exp(-ΔG‡/RT)
Zhurkov修正(1965): tf = t0·exp((U0-γσ)/kBT)
论文修正: 增加 ΔU_damage(微观损伤能量耗散)
→ 时变老化模型 P(t) = P0·f(t,T,σ,D)

## 黏附平衡理论
拉开法 → 中间漆/底漆附着破坏 = CSSS临界点

## 风沙冲蚀
切削磨损(Finnie) + 变形磨损(Bitter) → 冲蚀量预测
应力使涂层变脆 → 耐冲蚀性能降低 → 精度>90%
