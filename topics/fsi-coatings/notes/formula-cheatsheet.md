# 论文公式速查表

> 戚彦福(2026) 钢桥涂层的老化机理与耐久性研究

## 第2章: 热循环空间特征

| 公式 | 物理意义 | 符号含义 |
|------|---------|---------|
| ε_th = (α_c - α_s)·ΔT | 热失配应变 | α: 热膨胀系数, ΔT: 温差 |
| σ_th(y) = E(y)·α(y)·T(y,t) | 热应力分布 | E: 模量, 随位置y变化 |
| β = f(材料,几何,循环参数) | 热力学等效系数 | 将非均匀温度等效为均匀能量 |
| σ_th,modified = β·σ_th,classical | 修正热应力 | 考虑约束和耗散 |

## 第3章: 修正RPT

| 公式 | 物理意义 | 符号含义 |
|------|---------|---------|
| k = (k_B·T/h)·exp(-ΔG‡/RT) | Eyring原始RPT | k_B: Boltzmann, h: Planck |
| t_f = t_0·exp((U₀-γσ)/k_BT) | Zhurkov修正 | U₀: 活化能, γ: 应力敏感 |
| U_eff = U₀ - γσ - ΔU_damage | **本文创新: 微观能量驱动** | ΔU_damage来自于微观缺陷发展 |
| P(t) = P₀·exp(-A·exp(-U_eff/RT)·t) | 时变老化模型 | P: 性能(附着力/厚度) |

## 第4章: 耐久性量化

| 公式 | 物理意义 |
|------|---------|
| D(t) = 1 - P(t)/P₀ | 耐久性损失指标 |
| ln(k) = ln(A) - U₀/(R·T) | Arrhenius标定活化能 |
| k_eff ∝ exp(-(U₀-γσ)/RT) | 有效反应速率 |

## 第5章: 动应力

| 公式 | 物理意义 |
|------|---------|
| σ_ad = F_max/A | 拉开法附着强度 |
| W_c = ∫₀^δ σ(δ)dδ | 内聚能(断裂能) |
| W_total = W_e + W_p + W_c | 能量耗散分解 |

## 第6章: 风沙冲蚀

| 公式 | 物理意义 |
|------|---------|
| W_cut = (M·v²/p)·f(α) | Finnie切削模型 |
| W_def = M·(v·sinα-v_e)²/(2ε) | Bitter变形磨损 |
| W_total,modified = (W_cut+W_def)·f(σ,T,UV) | **本文修正: 多因素耦合** |
| L = f(W_total, h, h_min) | 寿命预测模型 |
