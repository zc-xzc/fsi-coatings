# 涂层材料参数参考

> 用于数值模拟输入的参数 | 来源: 戚彦福论文 + 文献 | 持续补充

## 三种涂装体系

| 参数 | 普通型 | 长效型 | 水性体系 |
|------|--------|--------|---------|
| 底漆类型 | 环氧富锌 | 环氧富锌 | 水性环氧富锌 |
| 中间漆 | 环氧云铁 | 环氧云铁 | 水性环氧云铁 |
| 面漆 | 聚氨酯 | 氟碳 | 水性丙烯酸 |

## 材料力学参数

### 涂层 (聚合物)
| 参数 | 数值范围 | 说明 |
|------|---------|------|
| 杨氏模量 E | 1~5 GPa | 温度/老化影响大 |
| 泊松比 ν | 0.3~0.45 | 聚合物 |
| 密度 ρ | 1000~1500 kg/m³ | |
| 热膨胀系数 α | 5e-5 ~ 1e-4 /K | 比钢材大4~10倍 |
| 导热系数 k | 0.15~0.4 W/(m·K) | 绝热材料 |
| 比热容 cp | 1000~2000 J/(kg·K) | |

### 钢基材

## 热循环参数

| 参数 | 典型值 | 说明 |
|------|--------|------|
| T_min | -20~0 °C | 冬季低温 |
| T_max | 40~60 °C | 夏季高温(阳光直射) |
| 升降温速率 | 1~5 °C/min | |
| 保温时间 | 0.5~2 h | |
| 循环周期 | 按天/按季节 | |

## 冲蚀参数

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 颗粒速度 | 5~30 m/s | 风沙速度 |
| 冲蚀角 | 15°~90° | 临界角30°~45° |
| 颗粒直径 | 50~500 μm | 沙粒 |
| 颗粒密度 | 2650 kg/m³ | 石英砂 |
| 颗粒形状 | 角状/半角状 | 影响冲蚀率 |

## 老化参数 (RPT修正模型)

| 参数 | 物理意义 | 标定方法 |
|------|---------|---------|
| U₀ | 无应力活化能 | 不同温度拟合 |
| γ | 应力敏感系数 | 不同应力水平 |
| ΔU_damage | 损伤耗能 | 微观表征 |
| k₀ | 指前因子 | 截距拟合 |
