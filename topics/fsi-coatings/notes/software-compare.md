# 软件与工具对比

> 选择合适的工具，避免浪费学习时间

## FEM求解器

| 工具 | 语言 | 开源 | 优点 | 缺点 | 推荐场景 |
|------|------|------|------|------|---------|
| **FEniCSx** | Python/C++ | ✅ | 语法接近数学公式, 自动微分 | 学习曲线中等 | **首选: 学术研究** |
| FreeFEM | C++ | ✅ | 快速, 内置求解器多 | 语法独特 | 需要高性能FEM |
| deal.II | C++ | ✅ | 大规模并行, 文档好 | 纯C++上手慢 | 大规模计算 |
| CalculiX | C++ | ✅ | preCICE原生支持 | 前后处理弱 | FSI耦合 |

## CFD求解器

| 工具 | 开源 | 优点 | 缺点 | 推荐场景 |
|------|------|------|------|---------|
| **OpenFOAM** | ✅ | 功能全, 并行强, preCICE适配 | 学习曲线陡 | **首选: 涂层冲蚀CFD** |
| SU2 | ✅ | Python接口, 气动优化 | 多相流弱 | 空气动力学 |

## 耦合库

| 工具 | 开源 | 优点 | 缺点 | 推荐场景 |
|------|------|------|------|---------|
| **preCICE** | ✅ | 成熟, 多求解器, 教程丰富 | 学习适配需要时间 | **首选: 分区耦合FSI** |
| MOOSE | ✅ | 整体耦合, 能源领域成熟 | 特定领域 | 核工程多物理场 |

## DEM求解器

| 工具 | 开源 | 优点 | 缺点 |
|------|------|------|------|
| **LIGGGHTS** | ✅ | 开源, CFDEM耦合 | 文档少 |
| EDEM | ❌ | 商业, 功能全 | 收费 |

## 网格生成

| 工具 | 开源 | 优点 | 推荐场景 |
|------|------|------|---------|
| **Gmsh** | ✅ | 轻量, 脚本, FEniCS原生 | **首选: FEM网格** |
| Salome | ✅ | 全面, 参数化 | 复杂几何 |
| blockMesh | ✅ | 结构化网格 | OpenFOAM结构化 |
| snappyHexMesh | ✅ | 自动六面体 | OpenFOAM复杂几何 |

## 推荐学习路线

```
┌────────────────────────────────────────────┐
│         FEniCSx (FEM)                      │
│           ↓                                │
│         OpenFOAM (CFD)                     │
│           ↓                                │
│  ┌──── preCICE (耦合) ──── LIGGGHTS (DEM) │
│  │         ↓                               │
│  │    Gmsh (网格)                          │
│  │         ↓                               │
│  ParaView (可视化) + LaTeX (写作)           │
└────────────────────────────────────────────┘

入门: FEniCSx (FEM) + OpenFOAM (CFD)
进阶: preCICE (耦合) + LIGGGHTS (DEM)
专题: 相场法 (FEniCS扩展) + CZM (界面脱粘)
