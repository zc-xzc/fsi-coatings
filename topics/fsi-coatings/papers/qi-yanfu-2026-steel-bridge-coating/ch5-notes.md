## 5.1 黏附平衡理论与拉开法

### 黏附平衡理论 (Adhesion Equilibrium Theory)
- 涂层与基材的界面结合力 = 机械咬合 + 物理吸附 + 化学键合
- 外部荷载破坏界面平衡 → 裂纹萌生 → 扩展 → 脱粘

### 拉开法测试原理 (Pull-off Test)
```
原理:
  粘接试柱 → 垂直涂层方向施加拉力 → 涂层被剥离

测量值:
  - 附着强度 σ_ad = F_max / A (最大拉力/面积)
  - 破坏模式: 内聚破坏/附着破坏/混合破坏

规范: GB/T 5210-2006 《色漆和清漆 拉开法附着力试验》
```

### 内聚能计算
```
涂层内聚能 W_c = ∫₀^δ σ(δ) dδ

其中:
- σ(δ): 牵引-分离本构
- δ: 分离位移
- W_c: 单位面积断裂能
```

### 论文修正的黏附平衡模型
```
拉开法力学分析 → 多指标协同模型
考虑:
1. 涂层-基材界面应力分布
2. 各层(底漆/中间漆/面漆)的材料差异
3. 动应力循环导致的疲劳累积
```

## 5.3 关键结果

### 涂层破坏模式演变
| 加载次数阶段 | 破坏模式 | 说明 |
|-------------|---------|------|
| 初期 | 完好 | 无可见损伤 |
| 中期 | 微银纹 | 应力集中区域 |
| 后期 | 界面微裂纹 | 涂层/基材界面 |
| 临界 | 中间漆/底漆脱粘 | **CSSS到达** |
| 失效 | 大面积剥落 | 丧失防护 |

### CSSS的确定
> **CSSS: 拉开法测试发生中间漆/底漆的附着破坏时**

这是论文的一个重要结论:
- 不是面漆破坏(还没那么严重)
- 不是基材裸露(已经太晚了)
- 中间漆/底漆界面破坏 = "即将失效"的临界点

### 附着力与厚度变化
- 附着力: 随循环次数指数衰减
- 厚度: 初期变化小, 后期加速损失
- 应变量: 涂层与基材应变不协调 → 界面剪切应力

## 5.4 耐久性量化评定

### 能量耗散模型
```
W_total = W_elastic + W_plastic + W_crack

动应力下:
  W_elastic: 可恢复弹性能(加载→储存, 卸载→释放)
  W_plastic: 不可逆塑性能(分子链滑移)
  W_crack: 裂纹扩展能(界面脱粘)

CSSS对应: W_crack 开始主导能量耗散
```

## 5.5 与FSI的关联
- 动应力 → 疲劳 → 与流固耦合中的涡激振动(VIV)类似
- 拉开法的力学分析可以用**CZM内聚力模型**做数值模拟
- 涂层疲劳寿命预测 = FEM + 疲劳损伤模型
