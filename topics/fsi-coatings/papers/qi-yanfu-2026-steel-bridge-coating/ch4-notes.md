# 第4章 静应力与环境作用下基于老化机理的涂层耐久性量化分析

> 页码: 99-130 | 关键词: 耐久性量化、参数标定、CSSS判据、敏感性分析

## 4.1 耐久性量化模型

### 模型框架
基于第3章的时变老化模型, 建立耐久性量化指标:
```
D(t) = 1 - P(t)/P₀ = 1 - exp(-k_eff · t)

其中:
- D(t): 耐久性损失 (0→1)
- P(t)/P₀: 相对剩余性能
- k_eff: 有效反应速率(包含温度+应力+损伤)
```

### 模型参数标定方法
| 参数 | 标定方法 | 物理意义 |
|------|---------|---------|
| U₀ | Arrhenius图 (lnk vs 1/T) | 无应力活化能 |
| γ | 不同应力水平拟合 | 应力敏感系数 |
| ΔU_damage | 微观损伤表征 | 缺陷发展耗散能 |
| k₀ | 截距拟合 | 指前因子 |

## 4.2 宏-微观分析与耐久性评定

### 热循环作用 (4.2.1)
- 仅热循环下: 热失配应力驱动老化
- 宏观: 附着力/厚度变化
- 微观: 分子链断裂, 自由体积增加
- 耐久性: 涂层越厚 → 表面老化越严重 → 界面应力越大

### 热循环+静应力 (4.2.2)
- 静应力叠加 → 活化能降低 → 老化加速
- 应力方向影响: 拉应力比压应力更显著
- 模型预测误差: <5%

### 热循环+紫外线+静应力 (4.2.3)
- UV加速表面层光解 → 表层脆化 → 裂纹从表面萌生
- 三因素耦合 > 两因素 > 单因素 (非线性叠加)
- 耦合效应不能用单因素结果简单叠加

## 4.3 CSSS判据与参数敏感性

### CSSS综合判据
| 指标 | CSSS阈值 | 检测方法 |
|------|---------|---------|
| 附着力 | 降至初始的50% | 拉开法 |
| 厚度 | 损失初始的20% | 测厚仪 |
| 破坏模式 | 中间漆/底漆附着破坏 | 目视+显微镜 |

### 敏感性分析结果
- **普通型**: 温度最敏感(热活化主导)
- **长效型**: 应力最敏感(交联密度高)
- **水性体系**: UV最敏感(树脂易光解)

## 4.4 与FSI的关联
- 耐久性量化模型的参数敏感性 → 数值模拟需要重点校准的参数
- 第4章模型可以作为数值模拟的**理论基准**
- 不确定性量化(UQ) → 后续可结合数值方法做更精细的敏感性分析
