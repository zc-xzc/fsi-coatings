# 第3章 静应力与环境作用下考虑老化空间特征的涂层老化机理研究

## 3.1 速度过程理论(RPT)回顾与修正

### Eyring原始模型 (1936)
```
反应速率 k = (k_B·T/h) · exp(-ΔG‡/RT)
```
- ΔG‡: 活化自由能
- 温度T升高 → 速率指数增加

### Zhurkov应力修正 (1965)
```
寿命 t_f = t_0 · exp((U_0 - γσ)/k_B·T)
```
- U₀: 无应力时的活化能
- γσ: 应力做功降低活化能壁垒
- 物理意义: 应力使分子链断裂所需的能量减少

### 问题: RPT为什么不够?
1. RPT假设材料均匀 → 涂层老化是空间不均匀的
2. RPT只考虑外加应力 → 忽略了微观缺陷发展的能量耗散
3. RPT没有联系宏观现象与微观机制

### 论文的创新修正: 微观能量驱动机制

#### 核心思想
涂层老化过程中的微观结构演变(微裂纹/空隙/银纹)会**耗散能量**, 这部分能量应当从总活化能中扣除。

#### 数学表达
```
原始RPT活化能:          U = U₀ - γσ
论文修正:    U_eff = U₀ - γσ - ΔU_damage

其中 ΔU_damage = f(微裂纹密度, 空隙率, 银纹体积分数)
```

#### 修正后的时变老化模型
```
P(t) = P₀ · exp(-k_eff · t)
     = P₀ · exp(-A · exp(-U_eff/RT) · t)

其中:
- P(t): 涂层性能(附着力/厚度)
- P₀: 初始性能
- k_eff: 有效反应速率
- U_eff: 有效活化能
```

## 3.2 静应力+环境耦合试验

### 试验设计
**三种涂装体系:**
| 体系 | 描述 | 特点 |
|------|------|------|
| 普通型 | 标准环氧+聚氨酯 | 基准 |
| 长效型 | 加强环氧+氟碳 | 高耐久 |
| 水性体系 | 水性环氧+丙烯酸 | 环保 |

**四类加载工况:**
1. 仅热循环 (基准)
2. 热循环 + 静应力
3. 热循环 + 紫外线
4. 热循环 + 紫外线 + 静应力 (全耦合)

### 关键发现
| 发现 | 说明 |
|------|------|
| 附着力衰减 | 随老化时间指数下降, 应力加速衰减 |
| 厚度变化 | 先增后减(吸水→损失), 反映了综合老化 |
| 破坏模式演变 | 完好→银纹→微裂→开裂→剥落 |
| 应力加速效应 | 静应力加快劣化速率但不改变整体进程 |

## 3.3 CSSS分析 (安全使用临界状态)

### CSSS的定义
涂层**即将失效但尚未丧失防护能力**的状态

### 宏观判据
- 拉开法测试: 中间漆/底漆发生附着破坏
- 厚度变化: 达到某一临界阈值
- 附着力: 降至初始值的某一百分比

## 3.4 与FSI的关联
- RPT修正本质上是**多物理场耦合**问题(热+力+损伤)
- 这种耦合机制可以用数值方法(相场法)来模拟
- 附着力/厚度的时变曲线 → 验证数值模型的基准数据
