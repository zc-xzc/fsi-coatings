## 6.1 风沙冲蚀量预测模型

### 冲蚀基本理论回顾

**Finnie切削模型 (1960)** — 低角度冲蚀
```
W_cut = (M·v²/p) · f(α)   塑性材料

其中:
- M: 颗粒总质量
- v: 颗粒速度
- p: 材料流变应力
- f(α): 冲蚀角函数
```

**Bitter变形磨损理论 (1963)** — 高角度冲蚀
```
W_def = (M·(v·sinα - v_e)²) / (2·ε)    变形磨损

其中:
- v_e: 弹性极限速度
- ε: 变形磨损因子
- α: 冲蚀角
```

**总冲蚀量 = 切削磨损 + 变形磨损**
```
W_total = W_cut + W_def
```

### 论文的修正: 考虑应力与环境作用
```
W_total,modified = W_total · f(σ, T, UV)

其中 f(σ, T, UV) = 考虑:
- 应力使涂层变脆 → 切削磨损减少, 变形磨损增加
- UV使表面降解 → 冲蚀阈值降低
- 热循环 → 界面弱化
```

### 应力与环境对涂层的影响
> **关键结论: 应力与环境作用使涂层向脆性材料转化**
- 原始: 柔韧性好(聚合物)
- 老化后: 脆性增加(交联+断链)
- 脆性材料 → 耐冲蚀性能降低

## 6.2 冲蚀试验

### 试验设计
**多因素耦合冲蚀试验:**
| 工况 | 因素组合 | 目的 |
|------|---------|------|
| 1 | 热循环+冲蚀 | 温度对冲蚀影响 |
| 2 | 热循环+静应力+冲蚀 | 静应力对冲蚀影响 |
| 3 | 热循环+UV+静应力+冲蚀 | 全耦合 |
| 4 | 动应力+冲蚀 | 疲劳对冲蚀影响 |

### 关键指标
| 指标 | 物理意义 |
|------|---------|
| 冲蚀形貌 | 冲蚀坑的形状和分布 |
| 冲蚀磨损量 | 质量损失 |
| 临界冲蚀角 | 冲蚀量最大的角度 |

### 结果
- 冲蚀形貌随加载周期: 点蚀→坑→连片→剥落
- 临界冲蚀角: 约30°-45° (取决于涂层体系和老化程度)
- 预测精度 > 90%
- 考虑交互作用后预测精度提升最大19%

## 6.3 寿命预测与最小厚度设计

### 寿命预测模型
```
L = f(W_total,modified, h, h_min)

其中:
- L: 服役寿命(年)
- h: 设计厚度(μm)
- h_min: 最小允许厚度
- W_total: 年冲蚀量
```

### 寿命预测结果
| 涂装体系 | 仅静应力 | 仅动应力 | 规范要求 |
|---------|---------|---------|---------|
| 普通型 | <15年 | <15年 | 30年 ❌ |
| 长效型 | <30年 | **31.1年** | 30年 ✅ |
| 水性体系 | <30年 | **30.7年** | 30年 ✅ |

> ⚠️ **只有动应力作用下的长效型和水性体系满足规范30年要求**
