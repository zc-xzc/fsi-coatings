# 项目提案: 涂层多场耦合FSI数值模拟

> 第一个研究项目 | 方向: FSI + 涂层耐久性 | 状态: 方案阶段

## 1. 项目背景

戚彦福(2026)的博士论文通过**实验+理论**分析了钢桥涂层在多因素耦合下的老化机理, 提出了CSSS概念。然而该论文**未做数值模拟**, 其实验数据和理论模型可作为数值方法的验证基准。

## 2. 研究目标

建立钢桥涂层多场耦合老化的数值模拟框架, 实现:
1. 热-力耦合: 热循环下涂层应力分布的FEM模拟 (验证第2章)
2. 流固耦合: 风沙冲蚀的CFD-DEM模拟 (拓展第6章)
3. 断裂耦合: 界面脱粘的相场法/CZM模拟 (深化第5章)

## 3. 技术路线

```
Phase 1 (研一上, 1-2月):
  涂层热-力耦合FEM (FEniCSx)
  → 复现论文第2章热应力空间分布
  → 对比验证数值精度

Phase 2 (研一下, 2-3月):
  风沙冲蚀CFD-DEM (OpenFOAM + LIGGGHTS)
  → 单颗粒→多颗粒冲击
  → 冲蚀量预测对比论文第6章

Phase 3 (研一下-研二上):
  界面脱粘相场法 (FEniCSx扩展)
  → 动应力下界面裂纹扩展
  → 耦合热-力-损伤

Phase 4 (研二):
  完整FSI框架 (preCICE耦合)
  → 多物理场耦合模拟
  → 寿命预测数值框架
```
